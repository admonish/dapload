Connect a music library

Copy music from a NAS or shared network folder straight to your player. Files go directly from the share to the player without passing through this browser.

This server can’t connect to network shares yet. Whoever set it up needs to install the smbprotocol Python package, or use the Docker image, which includes it.

The share is only read, never changed. The password is saved on the server running this app. Anyone who can open this page can browse the share, so only use this on a network you trust.
